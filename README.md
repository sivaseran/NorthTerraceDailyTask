# North Terrace V1 — Firebase Connected

Connected to your Cloud Firestore project.

First run:
1. Upload the contents to GitHub.
2. Enable GitHub Pages.
3. Open login.html and use the manager PIN stored in Firestore.
4. Go to Setup and click Create Starter Weekly Template once.
5. Open General View. Today’s tasks will be generated from the weekly template.

Collections used: users, weeklyTemplates, dailyTasks, shiftCover.

Important: Firestore rules are currently open for V1 development. Tighten them before normal live use.

The starter schedule is sample data only and will be replaced by the complete North Terrace AM/PM schedule.
